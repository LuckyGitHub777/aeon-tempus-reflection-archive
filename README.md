# AEON-TEMPUS — Reflection Archive

A self-contained offline browser experience for human-governed reflection, uncertainty tracking, and decision review. Open [index.html](index.html) locally in a modern browser. The page has no account, backend, external scripts, telemetry, or remote API requirements. Export your work before closing the tab if you want to retain it.

This source edition intentionally omits the large embedded background illustration to avoid republishing artwork whose reuse rights have not been independently established. The reflection interface and interactive logic remain; the background uses its original gradient. The page is **symbolic/educational**, not evidence of time travel, anomalous physics, supernatural mechanisms, or scientific validation.
